# Startup animation source

The 11 runtime files in this directory were copied from the user-provided local
project `codex-startup-animation` on 2026-10-06. The original
project was not modified. Its README identifies the project as
**Codex Startup Animation** and describes the animation, image settings, and
temporary iframe renderer.

Dream Skin uses only the animation renderer with `wallpaperEnabled: false`.
Codex launch, profile selection, debugging endpoint verification, and skin
application remain owned by Dream Skin. No executable or independent launcher
from the source project is included here.

The original README states that no open-source license has been specified for
the project code. Character artwork and flower icons belong to their respective
rights holders; the presence of these materials in the source repository does
not grant redistribution or trademark-use permission. The included default
images are `assets/avatar.jpg` and `assets/artwork.jpg`; `assets/contours.js`
contains the contours matching that artwork. This copy does not assign a new
license to any of these files.
